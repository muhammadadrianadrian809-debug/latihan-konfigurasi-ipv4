🎯 Misi Pembelajaran

Dua komputer di laboratorium terhubung ke satu switch, tanpa router. Konfigurasikan keduanya agar dapat berkomunikasi pada jaringan 192.168.1.0/24. Setiap komputer harus memiliki alamat host yang berbeda dan menggunakan subnet mask 255.255.255.0.

Petunjuk: Gunakan IPv4 host dari 192.168.1.1 sampai 192.168.1.254. Jangan gunakan alamat jaringan 192.168.1.0 atau broadcast 192.168.1.255.

🧩 Isi Konfigurasi Jaringan

Masukkan alamat IP dan subnet mask untuk kedua komputer. Tidak diperlukan default gateway untuk skenario komunikasi lokal tanpa router ini.

💡 Ingat Konsepnya

192.168.1.0/24 berarti 24 bit awal digunakan sebagai prefiks jaringan. Dengan subnet mask 255.255.255.0, alamat seperti 192.168.1.10 dan 192.168.1.11 merupakan dua host berbeda pada subnet yang sama.

Permainan ini mengevaluasi konfigurasi alamat, bukan menguji koneksi perangkat sebenarnya. Pengujian menggunakan ping dilakukan pada kegiatan praktik atau simulasi berikutnya.
